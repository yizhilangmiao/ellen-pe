## 三·补、模拟器冒烟（MuMu，无真机时用这个）

```powershell
# 起模拟器 + 连 adb（端口 16384，约 50s 才好）
& 'E:\Program Files\Netease\MuMu\nx_main\mumu-cli.exe' control -v 0 launch
cd E:\ailian\工具\platform-tools
.\adb.exe connect 127.0.0.1:16384
.\adb.exe -s 127.0.0.1:16384 install -r -d "<apk>"
.\adb.exe -s 127.0.0.1:16384 shell am start -n cn.ellen.companion/dev.ellen.mobile.MainActivity
```

包名是 `cn.ellen.companion`（**不是** dev.ellen.mobile），主 Activity 才是 `dev.ellen.mobile.MainActivity`。

**点坐标必须换算**：WebView 的 CSS 视口 = 物理像素 ÷ 密度，MuMu 上密度 1.75，
所以 `dumpsys window` 里 `w1097dp h617dp` 才是 CSS 尺寸，`input tap` 吃的是物理像素。
拿不到坐标时用 `uiautomator dump`（Git Bash 下必须 `export MSYS_NO_PATHCONV=1`，否则 `/sdcard/...` 会被改写成 Windows 路径），
但 Chromium 的 a11y 树时有时无，dump 出来只有 `WebView` 一个节点是常态，不能当唯一依据。

**取证手段优劣**：`/proc/net/unix | grep devtools` 为 0 说明没开 `setWebContentsDebuggingEnabled`，CDP 连不上；
`console.log` 也不进 logcat（无 onConsoleMessage）。目前只能靠**截图 + `uiautomator dump` + `adb root` 读 leveldb** 三条腿。

## 三·补二、已知做不到的（别再试第二遍）

**Android 返回键接管不了**（2026-10-30 实测）。

- 试过 `window.history.pushState({elbs:1},"")` + `popstate`：按 `input keyevent 4` 直接退到桌面，`popstate` 不触发。
- 试过 `document.addEventListener("backbutton", ...)`（Cordova 标准事件）：同样不触发。
- 根因：`work/assets/public/index.html` **没有引 `cordova.js`**（只有 `ellen-startup-opening.js`），
  没有 Cordova 的事件通道；主 Activity 是自定义的 `dev.ellen.mobile.MainActivity`，
  `onBackPressed` 也不查 WebView 历史，直接 finish。
- 现在留了 `window.__ellenBack` 钩子（若哪天壳里 `evaluateJavascript` 调它，就自动接管）。
- 本版对策：信尾「收起来」+ 顶栏「‹ 信匣」两个 48px 显眼出口，加一行操作提示。
- 彻底修：改原生（dex，不在 `_dev_pack.py` 白名单）→ 排进 0.1.23。

## 四、控制台取证（出问题先看这个）

Chrome `chrome://inspect` 连真机 WebView，Console 里：

```js
window.__ellenLetterSync.state()        // 点数/阶段/未读/读取失败原因
window.__ellenLetterSync.sync()         // 手动重扫
window.__ellenLetterSync.debugReset()   // 清掉本地状态（不删聊天记录）
```

`state().detail.reason`：
- `idle` 还没扫 → 等一下或手动 `sync()`
- `no-db` 本地资料库还没建（新装没聊过天）→ 正常
- `no-profile` 没拿到当前角色 id → 记下来，回来补 profileId 兜底逻辑
- 其他字符串 = 真实报错，原样贴回来
