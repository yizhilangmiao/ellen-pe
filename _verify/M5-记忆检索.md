# M5 · 记忆检索 + 手记/记忆页（v0.3.0-m5）

> 目标：她记得的事要能被"这句话"叫出来，而不是每次都端同一盘。
> 老 bug ③「记忆召回永远同样 7 条」在这一版被换掉。

## 一、做了什么

| 文件 | 作用 |
|---|---|
| `app/web/src/app/core/chat/recall.js` | 召回打分：中文二元组（bigram）重叠 + 时间轻加权（0.15）；零命中回退最近 3 条 |
| `app/web/src/app/core/chat/session.js` | 发消息前调 `recall()`，把结果拼进 system 段（不进聊天记录、界面不可见） |
| `app/web/src/app/core/state.js` | 新增 `setRecall/getRecall`，`snapshot().recall` 供验收读取 |
| `app/web/src/app/ui/views/memory/memory.js` + `memory.css` | 记忆页真数据：`记忆/她的过去` 读 `memory`、`我们的回忆` 读 `journal` |
| `app/web/src/app/main.js` | `defineView('memory', createMemoryView())` 替换占位；暴露 `__ellen.recall` |

## 二、召回算法（为什么这样算）

```
score = hit + recency
  hit     = 命中二元组数 / sqrt(该条文本二元组总数)
  recency = max(0, 1 - 天数/90) * 0.15
入选：hit >= 0.16，按 score 倒序取前 6；一条都没命中 → 取最近 3 条
```

- 分母开根号：长文本不该因为"字多"就被压死。
- 时间只占 0.15：不让"新的"盖掉"对的"，这是老 bug ③ 的病根。
- 阈值 0.16：实测"猫"这类明确话题 hit≈0.92，闲聊命中≈0.3，噪声不进来。
- 回退：完全没交集时给最近 3 条，避免她像失忆。

**已知局限**：纯字面匹配，没有同义词表。「今天在公司被骂」不会命中「加班到很晚」——中文需要分词/向量才能跨过去，排到 M5 之后。

## 三、验收证据（MuMu 实例 2 / 127.0.0.1:16448 / APK 5,291,999 B）

**1) 区分度**（`_临时\m5-recall.js`，先灌 3 条不同主题记忆：猫 / 下雨天 / 加班）

```json
{"cat":["猫:1.068","安静的一天:0.316"],
 "rain":["下雨天:0.368"],
 "work":["安静的一天:0.316"]}
```

三句不同的话召回结果不同 —— 旧版这里会是雷打不动的同一批。

**2) 端到端（真模型 DeepSeek）**（`_临时\m5-recall-e2e.js`）

问：「我家那只猫今天又不吃东西了，你说我该怎么办？」

```json
{"configUsable":true,"model":"deepseek-flash",
 "recall":[{"kind":"memory","title":"猫","score":1.068},
           {"kind":"journal","title":"安静的一天","score":0.316}]}
```

回复首句：

> 记得，是豆豆，三花猫，最近一直不爱吃东西，你很担心。

「豆豆」「三花猫」**只存在于被召回的那条 memory 里**，聊天记录里没有 —— 证明召回内容真的进了模型上下文。

## 四、踩的坑

1. **相对路径深度**：`ui/views/memory/memory.js` 到 `strings.zh.js` 要 `../../../`（memory→views→ui→app），写到 `../../` 时 vite 报
   `Could not resolve "../../strings.zh.js" from "src/app/ui/views/memory/memory.js"`。
2. `window.__ellen.recall` 忘记先 `import { recall }` 会 ReferenceError，构建不报（运行时才炸）。
3. `state.setRecall?.()` 用可选链先写上，方法后补也可以 —— 但补完必须重编，否则 `snapshot().recall` 永远空数组。
