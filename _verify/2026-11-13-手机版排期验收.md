## 三、这一轮修掉的宿主兼容问题（重要，会再犯）

1. **WebView 是 Chrome 110，不支持 `color-mix()`（需 111+）**。写进去整条 CSS 声明失效（不是降级，是消失）。实测 `CSS.supports('background','color-mix(in srgb,#fff 50%,#000)') === false`。
   全仓共 46 处，已修 12 处（`welcome.css` 进度点、`call.css` 3 处、`chat.css` 3 处纯字面量、粉晕渐变加 rgba 兜底），**其余 34 处仍在**（`memory.css` 10、`model-card.css` 6、`chat.css` 剩 4、`tokens.css` 3、`zz-frame.css` 2、`settings.css` 2…），见「四」待定项。
   写法：能算的写死 rgba；要渐进的写两行（先 rgba 兜底，第二行 color-mix 覆盖）。
2. **站酷快乐体（EllenKuaiLe）的「0」字形本身就是圆角方框**，不是缺字。计时/计数类要换等宽字体：`font-family: ui-monospace, "Roboto Mono", "Droid Sans Mono", monospace`。
3. **`adb shell input tap` 吃物理像素**，页面坐标要乘 `devicePixelRatio`（竖屏实例 dpr=2.5）。稳妥做法：CDP 里 `document.querySelector(sel).click()`。
4. 盖上 App 重装后 debug socket 名会变（`webview_devtools_remote_<pid>`），每次要重新 `adb forward`。
