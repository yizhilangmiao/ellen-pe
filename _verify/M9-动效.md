# M9 批 4 · 动效层（七条节拍 + 降级链）

> 2026-11-10 · 会话 dsh:e54e06 · 装机实测 APK 100,386,386 B（`0.3.0-m7`）
> 规格来源：`E:\ailian\md笔记\手机版UI重构方案-绝区零.md` §5（1C 全 ZZZ 硬切）

## 一、铁律（写在 `styles/zz-motion.css` 开头）

- 只动 `transform` / `opacity` / `filter` / `background-position`；
  **禁动** `box-shadow` / `width` / `height` / `top` / `left` / `margin` / `padding`（全是重排或重绘大户）。
- 曲线不用 `ease` / `ease-in-out`；`linear` 只给「按下反馈」与「无限循环」。
- 退出 = 进入 × 0.8。
- 单屏同时进行 ≤ 3 个；聊天区 = 1 个循环（等待三点）+ 1 个一次性（气泡入场）。

## 二、七条节拍与实测

| # | 场景 | 规格 | 实现 | 实测 |
|---|---|---|---|---|
| 1 | 页面切换（tab / push） | 180ms `--z-e-out`，旧页直拔 | `router.js` `activate()` 里给新页挂 `.is-entering`，两帧后摘；`@keyframes zz-page-in` = `translateY(4u)` + opacity | `animationDuration: 0.18s`，`sawEntering: true`，200ms 后归零 |

## 三、降级链（`ui/motion-guard.js`）

```js
initMotionGuard(root) → { reduce(), isReduced() }
```

1. **系统减弱动效**：`prefers-reduced-motion: reduce` 命中 → 根节点 `.reduce-ui-motion`；运行中改系统设置也跟随（`mq.addEventListener('change')`）。
2. **低端机探测**：首帧起测 `requestAnimationFrame` 间隔，连续 30 帧 > 33ms（≈30fps 以下）判低端机 → 加 `.reduce-ui-motion` 并写 `localStorage['ellen.ui.motion']='reduce'`（下次启动直接降级，只测前 90 帧，避免把用户操作造成的长帧算进去）。
3. **键盘弹起**：`visualViewport.height < base * 0.75` → `root.dataset.input='keyboard'`，给循环类动效（`.zz-anim-float`）留开关。

CSS 两侧收口（用 `0.01ms` 而不是 `none` —— 否则等 `animationend` 的 JS 会永久挂住）：

```css
@media (prefers-reduced-motion: reduce) { .ellen-app * { animation-duration:.01ms!important; transition-duration:.01ms!important; } }
.ellen-app.reduce-ui-motion * { animation-duration:.01ms!important; transition-duration:.01ms!important; }
.ellen-app[data-input='keyboard'] .zz-anim-float { animation: none; }
```

实测：手动 `__ellen.motion.reduce()` → 根节点带上 class、`animationDuration: 1e-05s`、`localStorage['ellen.ui.motion']="reduce"`；清掉键 + 重启后 `reduce:false`、`ls:null`（说明低端机探测在模拟器上**没有误判**）。

## 四、动效预算核对

- 聊天页稳态：等待三点（循环 1 个）+ 气泡入场（一次性 1 个）= 2，未超 3。
- 抽屉打开时：面板位移 1 + 遮罩 1 + 页面内容硬切（不算动效）= 2。
- 全程零 `box-shadow` 动画；按下反馈用 `filter: brightness()` 代替硬影收放（阴影动画会掉帧）。

## 五、坑

1. **`window.__ellen.motion = …` 写在 `__ellen` 字面量之前会整页白屏**（同批 3 的 drawer 坑），已改成塞进字面量。
2. **`render()` 每次都会重建所有气泡**（`stream.innerHTML = ''`），所以入场动画必须靠 `painted` 标记区分「首屏」与「增量」，否则每次切页都像下暴雨。流式增量走 `patchLast()`，不动 class，不会重播。
3. **抽屉关闭动画期间再次打开**会同时带 `.is-closing` 与 `.is-open`，两个 `both` 动画打架 → `open()` 里先摘 `.is-closing`。
4. **`.el-segment` 在设置页叫 `.el-settings-segment`**，第一版只写了前者，量出来 `transitionDuration: null`；补选择器后 `0.12s`。凭类名猜选择器必须实量。

## 六、没做的

- 页面**退场**动效（旧页直拔是规格要求，不是欠账）。
- 里程碑 glitch 目前只挂「相处天数 ×100」，其他 A 档时刻（首次达成、纪念日）等有产品口径再加。
- 低端机门槛 30 帧/33ms 是经验值，真机上若误判可调 `motion-guard.js` 的 `SLOW_STREAK`。
