## 二、验收证据（2026-11-03 14:21，MuMu 实例 1）

CDP 读 `window.__m1`：

```json
{"pluginPresent":true,"echoOk":true,"echoRoundTripMs":73,"rejectOk":true,
 "rejectCode":"text 必填且必须是字符串","eventOk":true,"platform":"android",
 "webview":"Chrome/110.0.5481.154","errors":[],"done":true}
```

- 请求/响应往返 **73 ms**，`echo({text})` 原样返回，长度与原生时间戳都对。
- reject 分支：不传 `text` → 收到 `text 必填且必须是字符串`（旧包语义是 code+message，M2 统一成 `INVALID_ECHO` 这种机器码，文案走资源）。
- 原生 → JS 事件：`notifyListeners("echoEvent")` 2 s 内到达，payload 的 `requestId` 与 JS 侧一致（证明事件不走轮询、不串号）。
- 环境：`platform=android`、`origin=https://localhost`、`Capacitor=native`、`isPluginAvailable('Echo')=true`。

## 三、意外收获：Capacitor 8.6.0 core 自带 4 个社区插件

新壳不写任何插件时，`Capacitor.PluginHeaders` 里已经有：

| 插件 | 自带方法（不含 add/removeListener 等 5 个自动方法） | 旧包契约 | 结论 |
|---|---|---|---|
| SystemBars | hide / show / setStyle / setAnimation = **4** | 同 4 | 一致，**不用自己写** |
| CapacitorHttp | patch/request/post/get/delete/put = **6** | 同 6 | 一致，**不用自己写** |
| CapacitorCookies | deleteCookie/clearCookies/getCookies/clearAllCookies/setCookie = **5** | 同 5 | 一致，**不用自己写** |
| WebView | persistServerBasePath/setServerAssetPath/setServerBasePath/getServerBasePath = **4** | 同 4 | 一致，**不用自己写** |

→ M0 契约里那 26 个「社区四件套」方法由 androidx/core 依赖白送，M2 只需写自有 `Ellen*` 的 **158** 个。
→ 旧包 `App:12`（非自动 7 个）仍需 `com.capacitorjs:app` 依赖，M2 第一批加上。

## 四、踩到的坑（都会复发，已写进踩坑库待登记）

1. **中文路径**：AGP 直接拒 `E:\ailian\艾莲手机版\...`，报 `Your project path contains non-ASCII characters`。解法 `android.overridePathCheck=true`；实测 aapt2 / kotlinc / d8 / 打包全过，只有一条无害警告 `Failed to stat ... android-36\android.jar`。
2. **阿里云 public 镜像缺 Capacitor 的 aar**：`com/capacitorjs/core/8.6.0/` 下 pom 有、aar 404，而 Gradle 把「元数据命中、制品缺失」判为该仓失败，**不会自动换下一个仓**。解法：`dependencyResolutionManagement` 里只留 `google()` + `mavenCentral()`（pluginManagement 仍可走阿里云）。
3. **pwsh 会吃掉 `-Dfile.encoding=UTF-8`**：不加引号时被拆成任务名 `.encoding=UTF-8`，报 `Task '.encoding=UTF-8' not found`。要么加引号，要么写进 `gradle.properties` 的 `org.gradle.jvmargs`（本工程用后者）。
4. **xml 注释里不能出现 `--`**：`<!-- M3 再搬进 --ellen-* 变量表 -->` 直接编译失败（`注释中不允许出现字符串 "--"`）。
5. **删 manifest 的 `android:icon` 不能用 PowerShell 的 `-replace` 拼 CRLF**：文件是 LF，替换静默不生效，白跑一轮构建。要改就用结构化编辑。
6. **首次构建会自动装工具**：Build-Tools 34（AGP 8.7 时代）与 platform android-36 都由 Gradle 自动下载，无需手点 sdkmanager。
7. **Gradle 版本必须跟 AGP 走**：AGP 8.7.3 最高只认 compileSdk 35，而 Capacitor 8.6.0 拉来的 androidx.core 1.17.0 要求 AGP ≥ 8.9.1 + compileSdk 36。最终组合：**Gradle 8.11.1 + AGP 8.9.2 + Kotlin 2.1.0 + JDK 21 + compileSdk 36**。
