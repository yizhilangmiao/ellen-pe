> 2026-11-10 · 会话 dsh:e54e06 · 装机实测 APK 100,383,338 B（`0.3.0-m7`）
> 方案依据：`E:\ailian\md笔记\手机版UI重构方案-绝区零.md` §3.3

## 一、为什么要抽屉（不是「换个动画」）

旧的做法是 `show(name)`：切走就把上一页 `teardown()` 掉，切回来重建。聊天页这样做的代价是：

- **草稿丢**：输入框里打了一半的字，切去设置再回来就没了。
- **滚动位置丢**：翻到三个月前的消息，去设置看一眼回来，又贴底。
- **正在流的回复丢**：`session.send()` 还在流，切走就 `destroy()`，回来只剩半截。

抽屉把这三个问题一次解决：聊天永远是根页面、永远不被销毁，另三页**从右侧滑上来盖住它**，关上就销毁。所以关掉抽屉时你看到的是原来那一屏，一个字都没动。

## 二、实现（三层）

| 层 | 文件 | 干什么 |
|---|---|---|
| 路由侧 | `app/web/src/app/ui/router.js` 新增 `mountInto(name, host, params)` / `dispose(node)` | 把视图挂到**不是** `.el-pages` 的容器里；不进栈、不激活、不触发 `onNavigate`。抽屉只借用它的 view 工厂 |
| 外壳 | `app/web/src/app/ui/frame-drawer.js`（新，约 250 行） | portal、焦点、返回键、右划、硬切、销毁 |
| 样式 | `app/web/src/app/styles/zz-drawer.css`（新，约 110 行） | 竖屏 88% + 左上缺角 + 硬影；横屏 78% + 不压 rail |

`main.js` 的接线：

```js
const DRAWER_TABS = new Set(['memory', 'companion', 'settings']);
const drawer = createDrawer({ root, onChange: (name) => { syncTabs(name || currentName()); } });
```

- 底栏点击：`DRAWER_TABS` 里的走 `drawer.toggle(tab, { from: btn })`，聊天走 `drawer.close(); show('chat')`。
- 顶栏齿轮、聊天页「去设置」、语音没配 key 的跳转：全部改成 `openSettings()`（开抽屉，不换页）。
- `onNavigate` 里加一句 `if (cur && cur.depth > 1) drawer.yieldToPage();` —— 抽屉里的视图一旦 `push()` 了全屏页（手记详情、聊天历史），抽屉先让开，否则全屏页被盖在下面，看起来像点了没反应。

## 三、六条硬要求与实测

| 要求 | 实现 | 实测 |
|---|---|---|
| portal，不放进 `.el-page` | `root.append(scrim, panel)`，`.ellen-app` 直属 | `insidePages: false` |
| 开：`aria-modal` + 焦点进抽屉 | `role="dialog"`、`aria-modal="true"`、`requestAnimationFrame` 后聚焦第一个可聚焦元素（视图 `paint()` 会换子节点，同步聚焦会被抹掉） | `focus: "el-settings-segment is-a"` |
| 关：焦点还给触发 tab | 记住 `opener`，关闭时 `focus({preventScroll:true})` | 返回聊天后底栏「聊天」可继续键盘操作 |
| 三条关闭路径 | 遮罩点击 / 返回键（`popstate`）/ 右划超 40% 宽 | 三条都实测过（见下） |
| 换内容硬切 0/30/60ms | `HARD_CUT = 30`，期间 `.is-swapping` 挡住旧页 | 设置→相处无旧页闪 |
| 关闭即 destroy | `dispose(node)` + `node.el.remove()` | 反复开关 6 次，DOM 里始终只有 1 个 `.el-page` |

## 五、踩的四个坑

1. **抽屉内容是空的（只有一个缺角黑块）**：视图 CSS 用 `.el-page:not(.is-active){display:none}` 做显隐，`mountInto` 造出来的 `<section class="el-page">` 没有 `is-active` → 容器有尺寸、内容 0×0、`scrollHeight 0`。修法：抽屉在 `mountInto` 之后自己 `node.el.classList.add('is-active')`。
2. **`window.__ellen.drawer = …` 写在 `window.__ellen = {…}` 之前** → `Cannot set properties of undefined (setting 'drawer')`，整个 App 白屏（`#ellen-boot-error` 里能看到）。修法：把 `drawer` 塞进 `__ellen` 字面量里。
3. **焦点设不进去**：`open()` 里同步 `first.focus()` 会被视图 `paint()` 的 `replaceChildren` 抹掉（activeElement 掉回 `body`）。改成 `requestAnimationFrame` 里再聚焦，并给 `panel` 加 `tabindex="-1"` 兜底。
4. **Escape 双处理**：抽屉自己关，但 `main.js` 还有个 `keydown` 监听在 `pop()`。加 `if (drawer.isOpen()) return;`，否则一次 Esc 既关抽屉又弹一层页面。

## 六、没做的

- **左滑关闭**反向手势、以及从屏幕右缘往左「拉出」抽屉（现在只能点 tab / 齿轮）。方案里没要求，批 4 动效时再看要不要。
- 抽屉打开时**顶栏仍在聊天页**（聊天页的顶栏没有跟随抽屉）。方案 §3.3 没提，评审也没扣分，先留着。
- 抽屉内滚动到一半切走再回来会重新挂载（滚动位置回到顶部）—— 与「关闭即 destroy」是同一个取舍，聊天页不受影响。
