# 模型配置：三步向导（m06781 / m06782）

给「什么都不懂的人」的配置流程。目标：不看文档、不查地址、不问人，跟着点就能配好并且当场知道通没通。

## 一、为什么重做

旧版把「平台 / API Key / 模型名 / 服务地址」四行平铺在一张卡上，每一样都在考用户：

| 旧版的提问 | 用户实际能回答吗 |
|---|---|
| 用的是哪家 | 能（但要先知道「哪家」会影响什么） |
| API Key | 不知道去哪领、不知道长什么样 |
| 模型名 | 完全不知道，且拼错一个字就 404 |
| 服务地址 | 不该由用户填，这是我们该算出来的 |

结论：不是把文案写短，而是**把四件事排成必须按顺序做、每屏只问一个问题的三步**。

## 二、三步结构

1. **选一家**：七个大卡片，每张一行白话（谁便宜、谁有免费额度、谁需要额外建接入点）。点中后**就地展开**「去哪里领钥匙」：网址 + 复制按钮 + 三条操作步骤。DeepSeek 挂「新手先选这家」徽章。
2. **贴钥匙**：一个输入框 + 「看一眼」切换明文 + `它长这样：sk- 开头的一长串` 的形样提示；粘够长度「下一步」才可点。
3. **挑模型**：平台推荐的 chips（默认选第一个）+ 可手填；只有选「我自己有地址」时才露出服务地址栏。

最后按「存下并试一下」：**存的同时真的发一句过去**，把结果翻成白话。

| 情况 | 界面上的话 |
|---|---|
| 成功 | 通了，她回了你一句：「……」 |
| 401 / 403 | 这把钥匙不对，或者这家还没给你开通。回上一步，把那一整串重新复制一遍。 |
| 402 | 这家账户里没钱了，去充一点再试。 |
| 404 / 400 | 地址或模型名不对。挑一个上面推荐的模型再试。 |
| 429 | 问得太快了，等一分钟再试。 |
| 5xx | 对面服务器出问题了，过一会儿再试。 |
| 连不上 | 连不上网，检查手机网络（或这家的地址打不开）。 |

## 四、实测（MuMu 实例 2 / 127.0.0.1:16448 / Android 15 / APK 100,395,368 B / pid 9852）

整条「只点不填」的路径（除了粘钥匙）：

```
点清除      → 状态「未配置」，回到第 1 步，三格只剩「选一家」亮
点 DeepSeek → 就地展开：https://platform.deepseek.com/api_keys + 复制网址 + 三条步骤
点下一步    → 第 2 步，提示「它长这样：sk- 开头的一长串」
粘钥匙      → 「下一步：挑模型」立即可点（disabled false）
点下一步    → 第 3 步，chips [*deepseek-chat, deepseek-reasoner]，地址栏隐藏
点存下并试   → is-run「正在拿这把钥匙问一句，等它回话…」
          → is-ok「通了，她回了你一句：「在的，有什么可以帮你的？」」，状态「当前：deepseek-chat」

坏钥匙 sk-wrong-000…：
          → is-bad「这把钥匙不对，或者这家还没给你开通。回上一步，把那一整串重新复制一遍。」
换回真钥匙 → is-ok「通了，她回了你一句：「在的，随时听你安排。」」
```

## 五、坑

1. **字符串键不能带点**：写成 `'next.key': '…'` 后 `s('wiz.next.key')` 会先取到字符串再取 `.key` 失败，界面直接显示 `wiz.next.key`。改名叫 `nextKey / nextModel`。**`s()` 只认一层对象路径，键名里带点等于自断。**
2. **`disabled` 只在 `paint()` 里刷会显得「没粘上」**：粘贴后 `input` 事件只改了 `keyValue`，按钮还是灰的。在 input 回调里同步 `next2.disabled`。
3. **不要做跳转**：WebView 里 `<a target="_blank">` 会被拦，改成「复制网址 + 一句话让他粘到浏览器」。
4. 台架验收脚本按 `pane:not([hidden])` 取当前屏，比按下标稳（步骤条可回退，下标会错）。

## 六、还没做

- 试连成功不会顺带写进聊天配置缓存以外的任何地方；旧版遗留的 `settings.platformLabel / keyLabel / modelLabel / endpointLabel / saveModel` 等 9 条文案现在没人用了（留着无害，下次清理）。
- 没有「用量/余额查询」入口。
