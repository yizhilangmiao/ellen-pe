## 二、用例

### TC-01 安装与首启 ✅ 已验
- 已验见〇。**还需你确认一件**：桌面「艾莲」图标是粉色心形（不是系统默认机器人）。
- [ ] 图标正常

### TC-02 权限引导
- **前置**：`adb shell pm revoke cn.ellen.companion2 android.permission.RECORD_AUDIO`
- **步骤**：聊天页按住麦克风 → 弹「允许录音吗」→ 允许 → 再按住说话。
- **过**：弹框出现；允许后能录；拒绝后提示「没有麦克风权限」而不是崩。

### TC-03 模型配置向导（可跳，密钥已在）
- **步骤**：设置 → 聊天模型 → 重新配置 → 三步走完 → 「存下并试一下」。
- **过**：第 1 步各平台大卡可点、带「去哪领钥匙」+ 复制按钮；第 2 步粘 key 后「下一步」立刻变亮；第 3 步试连 10 s 内显示「通了，她回了你一句…」。
- **反例**：故意输错一位 key → 「这把钥匙不对…」而不是英文报错。

### TC-04 聊天流式（P0）
- **步骤**：发「在吗？我今天有点累」。
- **过**：首字 < 3 s；文字**逐块**变长（不是等半天一次蹦出整段）；结束后气泡不闪；杀掉 App 重进，两条还在。

### TC-05 停止生成
- **步骤**：发一句长问题，出字后立刻点「停止」。
- **过**：已出的半截**留着**（不替换成「（已停止）」），下面小字标「已停止」；重进仍在。

### TC-06 错误文案
- **步骤**：设置 → 聊天模型 → 模型名改成 `nope-model-xxx` → 存 → 发一句。
- **过**：气泡「这次请求被服务端退了。多半是模型名不对…」；输入框上方系统条写 `HTTP 400 · invalid_request_error · DeepSeek`，可点掉；**气泡里不许出现原始 JSON**。
- **收尾**：改回 `deepseek-chat` 并保存。

### TC-07 系统朗读（P0）
- **步骤**：点她某句话下面的小喇叭；再点同一条。
- **过**：1 s 内出声、念的是纯文字（不念星号符号）；再点立刻停。
- **注意**：先确认媒体音量不是 0。

### TC-08 云端音色（P0）
- **步骤**：设置 → 声音 → 「试听一句」。
- **过**：3 s 内出声，明显比系统朗读自然；没 key 时提示「还没填朗读服务的 key」而不是没反应。

### TC-09 一键复刻音色（P1 · 花钱，先决定）
- **成本**：minimax 每建一个音色约 **9.9 元**，一次性。
- **步骤**：设置 → 声音 → 「一键复刻艾莲音色」，等 15–60 s。
- **过**：提示「复刻好了，音色 id 已自动填上」，再试听是新音色。
- **反例**：未实名要提示去实名；余额不足要提示没钱。

### TC-10 随机语音条（P1）
- **步骤**：设置 → 声音 → 打开「随机语音条」→ 连发 10–15 句（概率 1/7，太少碰不到）。
- **过**：某条回复下面出现波形条（不是文字气泡）；点一下「加载中 → 播放」，再点停；杀掉重进那条还在。

### TC-11 按住说话（P0）
- **步骤**：按住麦克风说一句 3–8 秒的话（如「帮我把客厅的灯关一下」），松手。
- **过**：松手后 1–2 s 文字出现在输入框（或直接发出，看开关）；**飞行模式也能转**（走手机里的离线模型）。
- **允许的瑕疵**：无标点、偶尔重复一个字（14M 小模型已知短板）。

### TC-12 记忆（P0）
- **步骤**：连聊 5 句带具体事实的话（宠物名、吃了什么、几点睡）→ 回忆 → 她的过去。
- **过**：出现新记忆卡（≤3 条），标题短、内容像她自己写的；「改」→ 改标题 → 保存立刻生效；「删」→ 连点两次 → 消失，杀掉重进仍不在。
- **界面要求**：编辑面板是深色卡片、字看得清（不能透明底）。

### TC-13 手记（P0）
- **步骤**：设置 → 手记整理 → 「让她现在写一篇」→ 回忆 → 我们的回忆 → 点最新卡 → 翻上/下一篇 → 看日历。
- **过**：写完显示标题；详情页米白纸 + **深墨字**；日历有手记的日子有底色、今天有描边、1–30 都清晰；页签那行（我们的回忆/她的过去/共同经历/星图/我眼里的你）**一行放得下、不被压扁**。

### TC-14 主动消息（前台）
- **步骤**：设置 → 主动消息 → 打开 → 「让她现在说一句」。
- **过**：10 s 内出现一句符合人设的话；同屏显示「下次大概：X月X日 HH:MM」。

### TC-15 主动消息（后台，P0）
- **步骤**（电脑上跑）：
  ```
  adb shell input keyevent KEYCODE_HOME
  adb shell am kill cn.ellen.companion2
  ```
  等 60 s。
- **过**：通知栏「艾莲」+ 一句生活化的话 + 粉色心形小图标；点通知进 App 并在聊天里看到这句。
- **判负提醒**：`am force-stop` 会清掉闹钟，用它测必然「失败」——那是方法错。

### TC-16 前台保活服务
- **步骤**：发一句长回答，出字过程中下拉通知栏。
- **过**：有「艾莲 · 在想这句话」常驻通知；回答结束通知自己消失。

### TC-17 备份（P0）
- **步骤**：设置 → 自动备份 → 「选文件夹…」→ **进 Documents 再点「使用此文件夹」→ 允许**（根目录不许选，Android 限制）→ 回来「立刻备份一份」→ 再点两次。
- **过**：提示「备份好了：艾莲备份-20261111-XXXXXX.ellenpack」；note 显示大小与「已有 N 份」；保留设 2 时第 3 次备完旧包被删。
- **必查**：文件真在 Documents 里、大小不是 0。

### TC-18 后台备份提醒
- **步骤**：设 3 天间隔并备份一次，然后切桌面等（或把 `nextAt` 改成过去时间）。
- **过**：到点来「该备份了，打开艾莲我自动存一份」；点进去 App 自动备一份。
- **注意**：这是提醒制（后台不生成包），原因见 `_verify/M7-备份-后台定时.md` 第二节。

### TC-19 导出 / 导入还原（P0，最该测）
- **步骤**：设置 → 导出资料包 → 存到手机 → 记下聊天条数 → `adb uninstall cn.ellen.companion2` → 装回 → 设置 → 导入旧版资料包 → 选包 → 确认框点「确定」。
- **过**：条数 / 手记 / 记忆与导出前一致；**确认框深色、字看得清**；相处天数不重置成 1 天。
- **注意**：卸载会丢备份目录授权，需重选（界面未提示，已知欠账）。

### TC-20 应用内更新（P1）
- **步骤**：`app\release.ps1 -BaseUrl <你的地址>` 产出 `latest.json`，丢到可访问的 https 静态站；设置 → 关于与更新 → 填地址 → 检查 → 下载 → 去安装。
- **过**：进度百分比走动；下载完「已就绪」；点「去安装」跳 **vivo 系统安装页**（只能真机验）；装完版本号变。
- **注意**：地址现在留空，未配时显示「还没有配更新地址。」是预期。

### TC-21 外观
- **步骤**：顶栏「⋮」→ 切深色/浅色；再进回忆看日历配色。
- **过**：浅色下米白纸上字仍是深墨（不能浅灰）；抽屉从左滑出有缺角；底栏选中项有荧光底条。

### TC-22 长列表（P2）
- **步骤**：造到 1,000 条消息左右（或用 `_临时/seed-memory.js`），进「她的过去」。
- **过**：进页 < 3 s；首屏 60 张卡，底部「再多看几条（还剩 N 条）」点一次加 60、60 ms 内完成；滑动不卡。

### TC-23 系统字号（P2）
- **步骤**：系统设置 → 显示 → 字体大小调「大」→ 回 App。
- **过**：标题/气泡/按钮不裁字不叠字（允许换行变高）。

### TC-24 卸载重装的数据状态（P2）
- **步骤**：`adb uninstall` → 装回 → 打开。
- **过**：空状态是「今天想聊点什么？先在设置里配置聊天模型…」这类引导，不是报错或白屏。
