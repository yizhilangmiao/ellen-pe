## 一、聊天（5 条）

**TC-01 发一句话，她回话**
- 点：聊天 → 输入框 → 打「在吗」→ 点右下箭头
- 算过：2 秒内出气泡，文字正常、不是英文、不是一大段 JSON
- 失败长相：气泡里出现 `{"error":...}` 或「服务端说这次请求不行」→ 记下来，把气泡里的整句抄给我

**TC-02 回复中途点停止**
- 点：说一句长一点的话（「跟我说说今天可以做点什么」）→ 她开始出字时点输入框右边的方框
- 算过：字立刻停住，**已经出来的字还在**（不是变成「（已停止）」一整句）
- 失败长相：整条回复被替换成「（已停止）」

**TC-03 切走再回来，回复还在**
- 点：发一句 → 立刻按 Home → 等 5 秒 → 从最近任务点回艾莲
- 算过：回复已经写完、落在聊天里；顶部没有红条
- 失败长相：回来发现只有你发的那句、她没回

**TC-04 断网后发消息**
- 点：开飞行模式 → 发一句 → 关飞行模式 → 再发一句
- 算过：第一句下面出现**深色提示条**「连不上…」；关掉后第二句正常回
- 失败长相：转圈不结束；或者第二句也发不出去（旧包有过这个死锁）

**TC-05 返回键三层**
- 点：进设置（抽屉）→ 按返回 → 应只关抽屉；再进「聊天历史」→ 按返回 → 应退回聊天；在聊天页按返回 → 应只弹提示
- 算过：一层一退，绝不「一按就回桌面」
- 失败长相：按一次直接回桌面 ← 这个如果是 23:29 之后装的包还出现，立刻告诉我

## 二、语音输入（按住说话，4 条）

**TC-06 第一次切语音态会要麦克风权限**
- 点：输入框左边的小麦克风图标
- 算过：弹系统「允许录音」；点允许后输入框变成「按住 说话」
- 失败长相：点了没反应（说明权限没弹出来，先看系统设置里艾莲的麦克风是否被拒过）

**TC-07 按住说一句**
- 点：按住「按住 说话」不放 → 说「今天想吃点热的」→ 松手
- 算过：松手后 1 秒内输入框里出现文字；字数差不多对
- 失败长相：文字是乱码（离线模型偶尔会）、或者空着。空着就把那句再说一遍

**TC-08 上滑取消**
- 点：按住 → 说话 → 手指往上拖到出现「松开取消」→ 松手
- 算过：什么都没发出去，输入框还是空的
- 失败长相：取消后还是发了一条

**TC-09 说完直接发（开关）**
- 点：设置 → 声音 → 语音输入 → 「说完直接发出去」打开 → 回聊天按住说话
- 算过：松手后**直接发出去**，不用再点箭头
- 失败长相：文字只在输入框里，没发

## 三、语音条（她发语音，3 条）

**TC-10 打开「随机语音条」**
- 点：设置 → 声音 → 第二个开关「随机语音条」打开 → 回聊天连发 10~15 句（随便聊）
- 算过：中间偶尔有一条**只有波形、没有文字**的气泡；点它能出声
- 失败长相：一条都不出现（概率 1/7，连发 15 句还没有就是没生效）

**TC-11 语音条点了不出声**
- 点：点那条波形
- 算过：变色 + 响；再点一次停
- 失败长相：点了没反应 → 看波形下面有没有小字说明（现在会写「这条念不出来」「还没配朗读的 key」）

**TC-12 两条语音不会一起响**
- 点：快速点 A 再点 B
- 算过：A 立刻停、B 开始
- 失败长相：两个声音叠在一起

## 四、朗读（2 条）

**TC-13 让她念出来**
- 点：设置 → 声音 → 「文字加语音朗读」打开 → 回聊天发一句
- 算过：她回完自动开始念，声音是**复刻音色**（不是手机自带的机械音）
- 失败长相：念的是机械女声 → 说明云端音色没生效，检查 minimax key 是否还在

**TC-14 点小喇叭单独念**
- 点：任意一条她说的话，气泡下面那个小喇叭
- 算过：念这一条；再点停

---

## 五、记忆与手记（4 条）

**TC-15 记忆能写进去**
- 点：聊天里说三件事（「我家猫叫豆豆」「我不吃香菜」「我加班到十点」）→ 聊够 4 句 → 去「回忆」→「她的过去」
- 算过：出现新卡片，标题是这三件事之一（可能要多聊几句才触发，20 分钟内只抽一次）
- 失败长相：一张新卡都没有 → 把「她的过去」截图给我

**TC-16 手改一条记忆**
- 点：任意记忆卡 → 「改」→ 改标题 → 保存
- 算过：卡片跟着变；重启 App 还在
- 失败长相：改完变回原样

**TC-17 删一条记忆要按两次**
- 点：卡片 → 「删」→ 再点一次
- 算过：第一次按钮变「再点一次就删」，第二次才消失

**TC-18 手记自动写**
- 点：设置 → 角色与陪伴 → 手记整理 → 「让她现在写一篇」
- 算过：几秒后提示「写好了：xxx」；去「我们的回忆」能看到那一天
- 失败长相：提示「这几句还太少」→ 这是正常的，先多聊几句再点

## 六、备份与迁移（3 条）

**TC-19 选文件夹 + 立刻备份**
- 点：设置 → 数据与迁移 → 自动备份 → 「选文件夹…」→ 选**通讯录/Documents 这类子目录**（不能选根目录）→ 「立刻备份一份」
- 算过：几秒后「备份好了：艾莲备份-日期-时间.ellenpack」；用系统文件管理器能在那个目录看到
- 失败长相：一直转圈 / 报「备份失败：…」

**TC-20 导出资料包（含语音）**
- 点：数据与迁移 → 「导出资料包」→ 存到下载目录
- 算过：提示「N 次改动 · X MB」；发过语音的话 X MB 里应该含音频体积
- 失败长相：导出后打不开 / 体积明显小于语音总量

**TC-21 换机恢复（可选，会覆盖当前数据，先备份！）**
- 点：卸载 → 重装 → 数据与迁移 → 「导入旧版资料包」→ 选那个 .ellenpack
- 算过：聊天记录、记忆、手记都回来；语音条还能播
- 失败长相：导入报错，或记录回来但语音全灰（灰 = 音频没进包，说明导出时是旧包）

## 七、设置向导（2 条）

**TC-22 模型配置三步**
- 点：设置 → 聊天模型 → 走完「选平台 → 粘钥匙 → 选模型 → 存下并试一下」
- 算过：「通了，她回了你一句：…」
- 失败长相：红字「这把钥匙不对…」→ 钥匙复制时少了字符

**TC-23 声音配置三步**
- 点：设置 → 声音 → 第一步的链接（会复制网址，粘到浏览器领 key）→ 第二步粘 key → 第三步「一键复刻艾莲音色」
- 算过：提示已复刻 + 试听能出声
- ⚠️ **这一步会花钱**：minimax 复刻音色约 **9.9 元/个**，你想省就跳过，用默认音色也能念

## 八、日常形态（2 条）

**TC-24 通知权限 + 主动消息**
- 点：设置 → 主动消息 → 打开「她会自己来找你」→ 允许通知
- 算过：开关变「开着」，显示「下次大概：…」
- 想立刻看效果：点「让她现在说一句」→ 几秒后她主动说一句，聊天里出现、底栏聊天图标右上角有粉点

**TC-25 后台还能发（硬骨头）**
- 做法：打开主动消息 → 回桌面 → **用最近任务把艾莲划掉**（不要用「强行停止」）→ 等 30~90 分钟
- 算过：通知栏出现她的消息（点进去能看到那句话）
- 失败长相：等到明天也没有 ← 这属于最需要报的问题

## 九、报问题给我时，带这三样

1. **哪一条**（比如 TC-07）
2. **截图**（连气泡里的字一起拍）
3. **如果聊天出错，把气泡里那一整句原文抄给我**（红字/深色条上的字都要）

## 十、已知会看到、但不是 bug 的

| 现象 | 为什么 |
|---|---|
| 她说的话偶尔冒 `**粗体**` 变粉色 | 故意的，强调用粉色（字形只有一个字重，加粗会糊） |
| 离线转写偶尔多一个字、没有标点 | 14M 模型就这样；云端转写更准但要走网 |
| 语音条 7 条里才出现 1 条 | 概率设定 1/7，不是坏了 |
| 「我眼里的你」写着「还没有足够的回忆」 | 消息太少时不硬编，聊够几天才写 |
| 设置里「星图 / 时间河」空着 | 这两个功能这版没做（旧包有，没进这轮范围） |
| 备份只能在子目录里选 | Android 11+ 不允许选根目录，系统限制 |
