# M17 · 返回键（四层裁决 + 双按退出）

日期：2026-11-11 · 状态：**已落地、已在模拟器验收**
方案来源：`md笔记\手机版-返回键与语音输入-方案-2026-11-11.md` 第一节

---

## 一、为什么原来一按就退出

`@capacitor/app`（`AppPlugin`）一直在原生侧注册着，但 **web 层一次都没监听 `backButton`**：
`grep 'backButton'` 在 `app\web\src\app` 下零命中。所以系统返回键 = 没人拦 = Activity 被
`finish()` = 直接回桌面，聊天里正在进行的草稿、滚动位置、甚至正在流的回复一起没。

批 3 之后又多了一个坑：抽屉为了吃返回键，自己 `history.pushState` 一次并监听 `popstate`。
如果返回键再走 `history`，一次会按掉两层（抽屉 + 页面）。

## 二、做法：把「谁能吃这一下」收成一条按优先级排序的链

新建 `app\web\src\app\core\back-stack.js`（约 120 行）：

```js
registerBack(fn, { priority, name })  // fn 返回 true = 吃掉；返回反注册函数
requestBack(ctx)                      // 从高到低问一遍，第一个 true 就停
installAndroidBack(onUnhandled)       // 装 App.addListener('backButton')
minimizeApp()                         // plugin('App').minimizeApp()
backChain()                           // 诊断：现在链上有谁
```

**主题词：只留一个 owner。** 抽屉不再碰 `history`，四层各自注册、各自反注册：

| 优先级 | 谁 | 行为 |
|---|---|---|
| 50 | `ui\memory-editor.js` | 面板开着 → 只关面板 |
| 40 | `main.js`（顶栏「⋯」） | 菜单开着 → 收菜单 |
| 30 | `ui\frame-drawer.js` | 抽屉开着 → 关抽屉（不切根页） |
| 20 | `ui\router.js` | `stack.length > 1` → `pop()` |
| 10 | `main.js` | 不在聊天页 → `show('chat')` |
| 0 | `main.js` | 兜底 → 双按退出提示 |

（60 号位留给语音录音中，等语音那块落地后由 `main.js` 注册。）

**退出用 `minimizeApp()` 不用 `exitApp()`**：回桌面即可，进程留着才能继续发主动消息、
收后台提醒；`exitApp()` 会把前台服务和闹钟一起带走。

## 三、逐层验收（MuMu 实例 2 / 127.0.0.1:16448 / Android 15 / APK 100,276,556 B / pid 29137）

链本身：

```
__ellen.back.chain() → [
  {name:"header-menu", priority:40}, {name:"drawer", priority:30},
  {name:"router", priority:20},      {name:"back-to-chat", priority:10}]
__ellen.back.probe() → {installed:true, native:true, page:"chat", depth:1}
```

逐层（每一步都用 `__ellen.back.fire()` 等价按一次返回）：

```
history 打开（depth 2, page "history"）→ fire → {page:"chat", depth:1}          ✓ 退一层
抽屉打开（{drawerOpen:true, drawerName:"settings", page:"chat"}）→ fire
                                       → {drawerOpen:false, page:"chat"}         ✓ 关抽屉，根页不动
菜单打开（{menuOpen:true}）→ fire      → {menuOpen:false, page:"chat"}           ✓ 只收菜单
兜底（onBackUnhandled）→ hintOn:true, 文案「再按一次就退出哦」,
                       盒子 {y:460, h:31, w:100}，2.2 s 后自动消失                ✓
```

**真机按键路径**（`adb shell input keyevent 4`）：

```
第 1 次 → 截图 shot-back-hint.png：输入条上方浮出「再按一次就退出哦」
第 2 次（2 s 内）→ topResumedActivity=app.lawnchair/.LawnchairLauncher
                  mCurrentFocus=app.lawnchair/app.lawnchair.LawnchairLauncher
                  pidof cn.ellen.companion2 → 29137（进程仍在，未被杀）
```

第 2 步是关键：**回桌面而不是退出进程**，`pidof` 有值就是证据。

## 四、坑

1. **抽屉的 `popstate` 必须删掉**，否则与返回键双处理（一次按掉两层）。删掉后 `guard` 变量
   与两处 `history.pushState/back` 一并清掉，抽屉不再碰 history。
2. **提示条的 `z-index` 要高于 `.el-chat-stream`**（它 `z-index:1` 且气泡溢出自己的盒子）。
   系统条当初就吃过这个亏：DOM 在、截图里看不见。本次直接给 `z-index:45`。
3. **Escape 不触发退出提示**：桌面调试按 Esc 不该弹「再按一次退出」。所以 Escape 走
   `requestBack()` 但不走 `onBackUnhandled()`。
4. `.el-exit-hint` 挂在 `.el-pages`（`position:relative`）里，`bottom` 用 `calc(78*var(--u))`，
   不改内联 style。

## 五、验收口（给后续回归用）

```js
__ellen.back.chain()          // 链上有谁（顺序即优先级）
__ellen.back.probe()          // {drawerOpen, drawerName, menuOpen, page, depth, hintOn, installed, native}
__ellen.back.fire()           // 等价按一次返回（不触发退出）
__ellen.back.onBackUnhandled()// 模拟兜底那一下（验收提示用）
```
