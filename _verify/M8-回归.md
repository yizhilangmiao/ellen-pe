## 五、已修的真 bug 清单（压测/实测中顺手发现并修掉的）

1. **`todayJournal()` 只取 60 篇 →「今天」被挤出窗口 → 一天写两篇**
   - 位置：`app\web\src\app\core\journal.js:70-83`
   - 病根：手记没有「按 day 查」的索引，只能按时间排序后截断，库里手记超过 60 篇（两个月就满）时，今天那篇可能落在截断之外，页面显示「今天还没写」→ 又新开一篇。
   - 修法：`listLatest('journal',{limit:60})` 找不到就用 `limit:0`（全量）兜一次。压测 503 篇时踩到并验证修好。
2. **`EllenSecureConfig` scope 白名单缺 `asr` / `tts` → 一写就 `Invalid scope`**
   - 位置：`app\app\src\main\java\cn\ellen\companion2\plugin\EllenSecureConfigPlugin.kt:21`
   - 病根：早期版本只认 `model` 与 `voice`，M6 语音一进来，`asr` / `tts` 两枚 key 直接写不进去，报错信息还指向调用点，容易查错方向。
   - 修法：`private val allowed = setOf("model", "voice", "asr", "tts")`（文件头 13-15 行留了这段注释）。
3. **`readKey()` 把整段 JSON 当 key 用 → 401，界面只说「key 不对」**
   - 位置：`app\web\src\app\core\speech.js:72-90`
   - 病根：历史某版把 `{"apiKey":"sk-…"}` 整段存进了密钥库，读出来直接拼 `Authorization` 必然 401，而且很难看出是格式问题。
   - 修法：读出来先判 `startsWith('{')`，是 JSON 就取 `obj.apiKey` 摊平成裸 key，解析失败返回空串（走「没配 key」的正常分支）。
